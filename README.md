## 🚀 What This Project Does

Enter any city name and instantly get its current **temperature**, **weather condition**, and **wind speed** — powered by the Open-Meteo API (free, no API key needed). The app first resolves the city to coordinates via a geocoding API, then fetches live weather data for that location.

Built entirely with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies.

---

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Displays current temperature
- 🌬️ Shows wind speed
- 📍 Shows city and country name
- ❌ Proper error handling for invalid or unknown cities
- 📱 Clean, responsive UI

## 🔌 API Used

**[Open-Meteo](https://open-meteo.com/)** — completely free, no sign-up or API key required.

| Step | API Call |
|------|----------|
| 1 | Geocoding API — converts city name to latitude & longitude |
| 2 | Weather API — fetches temperature, condition, and wind speed for those coordinates |
